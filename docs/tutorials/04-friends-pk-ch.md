# 好友互动与宠物 PK 教程

## 好友管理

1. 进入「宠物 → 好友」
2. 点击「刷新」拉取最新好友列表（来自萌卡账号的好友）
3. 每个好友显示：昵称、是否有宠物、宠物 ID

### 好友宠物

- 点击好友可查看其宠物资料（属性、等级、宠物 ID）
- 可以给好友的宠物设置/修改昵称标记

### 好友互动

- 对好友宠物进行互动（摸头/喂食等）
- 好友宠物互动计入每日统计

## 宠物 PK

PK 是对战玩法，双方宠物按战力对比决出胜负。

### 开始 PK

1. 宠物页点击「PK」
2. 选择对手：
   - **好友宠物**：从好友列表选择
   - **陌生宠物**：从公共池（PK 陌生人列表）选择
3. 点击「开始 PK」→ 系统结算胜负

### PK 结果

- 胜利：获得金币和经验，宠物 PK 榜积分上升
- 失败：消耗少量体力
- 支持查看 PK 历史记录和战力变化

### 自动 PK

「自动PK」功能可定时自动匹配并 PK：
- 配置：开启自动PK、设置频率（如每 30 分钟一次）
- 日志：查看每次自动 PK 的结果
- 建议在体力充足时开启，避免浪费

## 战力排行

「排行」页展示全服宠物战力 Top 榜，点击可查看上榜宠物资料。

> 注意：PK 对手（陌生宠物）数据可在管理端导入（stranger-pets）。
