# 宠物养护教程（喂养 / 洗澡 / 互动）

宠物有 4 项核心状态，需日常维护：

| 状态 | 影响 | 恢复方式 |
|------|------|----------|
| 饱食度 (hunger) | 过低宠物生病/无法学习 | 喂养 |
| 清洁度 (cleanliness) | 过低宠物生病 | 洗澡 |
| 活力/体力 (energy) | 活动需要消耗 | 时间自然恢复 |
| 金币 | 购买用品 | 打工/冒险 |

## 喂养

1. 进入「宠物」页面，点击「喂养」
2. 选择食物（食物可在「商店」购买，或查看当前库存）
3. 点击确认 → 宠物饱食度上升

> 谷物类食物提升饱食度最多；高级食物附带额外属性加成。

## 洗澡

1. 点击「洗澡」
2. 选择洗护用品（浴液/香波等）
3. 确认后清洁度恢复

## 互动

「互动记录」面板展示宠物与好友的互动时间线：
- 好友来访、被摸头、PK 等事件
- 每类事件有专属文案

## 属性成长

属性（力量/智力/魅力）通过以下方式成长：
- **学习类活动** → 智力为主
- **打工** → 金币 + 少量属性
- **冒险** → 力量为主
- **鼓励** → 活动期间提升效率

属性决定总战力（power），战力影响 PK 排名。
