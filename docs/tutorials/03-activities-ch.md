# 活动教程（学习 / 打工 / 冒险）

活动是宠物升级、获得属性与金币的主要途径。

## 开启活动

1. 宠物页点击「活动」
2. 选择类型标签：`学习` `打工` `冒险`
3. 选择具体项目（如「蹦蹦跳跳体能课」「萌芽夏令营」）
4. 点击开始 → 进入倒计时

## 活动类型说明

### 学习（school）
- 提升智力和部分力量
- 有多个课程选项，每项有固定时长（如 10 分钟）和奖励预览
- 职业等级越高，解锁的课程越多

### 打工（work）
- 主要产出金币
- 需要选择职业方向（换职业后选项更新）
- 体力消耗较大

### 冒险（adventure）
- 提升力量，可能获得稀有奖励
- 有冒险成功率/剧情分支

## 活动状态

- 活动开始后，「活动状态」面板显示剩余时间和进度条
- 同一时间只能进行一个活动
- **鼓励**：活动进行中点击「鼓励」，宠物会回复鼓励语条，效率提升

## 注意事项

- 活动需要消耗体力（fatigue），体力每天有限额（学习/工作/冒险分别计算）
- 活动即将结束时可以回来查看结果提示
- 若「开始活动」提示"当前版本过低"，为腾讯宠物服务端升级导致的全平台暂限，请等待平台版本更新
