# 常见问题排查（FAQ）

## 1. 页面提示「服务器暂时不可用」

原因：前端收到后端 HTTP 5xx 或非 JSON 响应。

排查步骤：
1. 检查萌卡连接：管理端 → 萌卡节点 → 状态是否为「已连接」
2. 若断开：点击「重新连接」，或在萌卡管理台确认插件服务（7879）在运行
3. 确认萌卡进程存在（任务管理器/系统服务：mengka-nt.exe）
4. 若反复断开：检查萌卡插件令牌是否仍有效，必要时重建插件服务并更新平台节点配置

## 2. 添加 QQ 账号报「账号已存在」

该 QQ 号已在萌卡中登录过。处理：
- 方案A：在萌卡管理台删除该账号 → 回到平台重新用密码添加
- 方案B：直接把萌卡中已登录的账号与平台绑定（需要管理员在数据库中建立绑定关系）

## 3. 添加账号报「QQ 密码登录请求失败」

- 密码错误
- 或该 QQ 触发风控（异地/新设备）→ 改用萌卡扫码登录，再绑定平台

## 4. 开始活动报「当前版本过低（135064）」

腾讯升级了 QQ 宠物接口版本校验，属**平台共性问题**（所有用户受影响）。等待 memgke-qq-pet 上游发布新版本后升级平台即可。鼓励/喂养/洗澡等不受影响。

## 5. 宠物页看不到数据

- 确认账号在线（QQ账号页 status=1）
- 确认宠物已激活（若新号需先在 QQ 宠物应用内激活）
- 刷新页面

## 6. 萌卡管理台打不开

- 检查萌卡进程与端口 7878
- 公网访问需隧道（cloudflared），隧道失效时用内网地址

## 7. 升级萌卡版本

1. 备份 data 目录
2. 停止萌卡进程
3. 替换 mengka-nt.exe / public / docs（保留 data）
4. 启动新版本
5. 确认插件服务（7879）与账号自动恢复
