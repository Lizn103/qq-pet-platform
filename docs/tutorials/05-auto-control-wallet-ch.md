# 自动托管与钱包教程

## 自动托管（Auto Control）

自动托管让宠物在你睡觉时也能健康成长。

### 开启方法

1. 宠物页 → 「自动托管」
2. 配置以下规则：
   - **自动喂养**：当饱食度低于阈值（如 30）时自动喂食
   - **自动洗澡**：当清洁度低于阈值时自动洗澡
   - **自动互动**：定时与宠物互动/鼓励
   - **执行计划**：设定时间段（如每天 08:00-23:00）
3. 保存并开启

### 查看托管状态

- `状态`页：当前规则与运行状态
- `日志`页：每次自动动作的记录（时间、动作、结果）
- `库存`页：食物/用品余量，库存不足时托管会暂停

> 自动托管需要账号在线且金币/物品充足。

## 钱包系统

### 金币获取

| 途径 | 说明 |
|------|------|
| 打工 | 主要来源 |
| 冒险/学习 | 少量金币 |
| PK 胜利 | 金币奖励 |
| 卡密兑换 | 输入卡密获得金币 |

### 卡密兑换

1. 「我的 → 钱包 → 卡密兑换」
2. 输入卡密（管理端生成的兑换码）
3. 兑换后金币立即到账，可在「流水」查看记录

### 转账

- （如果是管理配置的场景）可在钱包页向指定用户转账
- 转账记录作为流水保留

> 注意：添加 QQ 账号需要支付套餐费用（0 元套餐可免费添加），余额不足时会提示"金币余额不足"。
