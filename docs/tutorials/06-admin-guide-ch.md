# 管理端使用手册

管理端面向平台运营者，通过 admin 账号登录后访问（/admin）。

## 用户管理

- **用户列表**：查看所有注册用户（ID、用户名、角色、状态、金币）
- **状态管理**：启用/禁用用户（禁用后无法登录）
- **角色管理**：分配普通用户/admin 角色
- **密码重置**：为用户重置密码
- **钱包调整**：直接增/减用户金币（用于补偿、奖励）

## 套餐与卡密

### QQ 套餐
- 新建套餐：名称、价格（金币）、服务天数（如"按月套餐 30天"）
- 套餐决定用户添加 QQ 账号时的费用与时长

### 卡密管理
- 生成卡密：批量生成兑换码（指定金币面额/数量）
- 查询统计：查看已兑换/未兑换卡密
- 卡密用于用户钱包充值

## QQ 账号管理

- 查看所有用户的 QQ 绑定情况（QQ号、节点、服务到期时间）
- 解除绑定（用户违规时）
- 平台侧的"添加账号/登录/续期"都由用户自助完成

## 萌卡 NT 节点配置（核心）

1. 管理端 → 萌卡/机器人节点
2. 添加节点：
   - 名称：如「萌卡NT」
   - 主机：萌卡NT 所在 IP（本机用 127.0.0.1）
   - 端口：插件服务端口（萌卡WebUI里配置的正向WS，如 7879）
   - 令牌：萌卡插件服务的服务令牌
3. 保存后状态应显示「已连接」
4. 使用「调试」面板可手动执行萌卡 Action（诊断用）

> 常见状态：
> - 连接断开：萌卡未运行 / 令牌错误 / 萌卡重启过 → 重新连接
> - 已连接但账号离线：在账号页点登录

## 公告管理

- 发布公告（站点首页展示）
- 公告可设标题+内容+状态

## 审计日志

- 记录管理端操作（用户调整、卡密生成等）
- 用于追溯运营操作

## 系统设置

- 注册开关：是否允许用户自助注册
- 其他平台级配置项

## 官方机器人推送

- 配置 QQ 官方机器人（appid/secret）
- 「发送测试消息」验证推送链路
- 用于重要公告推送到用户 QQ
