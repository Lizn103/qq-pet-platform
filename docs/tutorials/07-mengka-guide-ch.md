# 萌卡NT 完整使用手册（全功能版）

萌卡NT（MengkaNT）是 QQ 协议机器人框架，QQ宠物平台依赖它连接 QQ 账号并调用宠物接口。

> 适配版本：v2.7.x ｜ 本机地址/账号见《运维手册》第 7 节；固定网址 https://mengka.jwerw.work

---

## 1. 快速上手

| 步骤 | 操作 |
|---|---|
| 启动 | 双击 `C:\mengka-nt\mengka-nt.exe`（或随开机自启） |
| 打开管理台 | 浏览器访问 `http://127.0.0.1:7878` 或 `https://mengka.jwerw.work` |
| 登录 | 首次初始化设置管理员账号密码；之后用该账号登录 |
| 检查 | 左侧「概览」看框架状态、协议加载、账号在线数 |

常驻服务：
- 管理台 WebUI：`:7878`
- 插件服务（正向WS）：`:7879`（平台通过它调用宠物 API）

---

## 2. 账号管理（核心）

### 添加 QQ 账号
1. 左侧「账号管理」→「添加账号」
2. 填写 QQ 号 + 密码 → 选择**协议**与**设备指纹**
3. 登录方式两种：
   - **扫码登录**（推荐）：生成二维码，手机 QQ 扫，验证码少
   - **密码登录**：输入 QQ 号密码，可能需滑块/短信验证
4. 登录成功 → 账号变「在线」，手机 QQ 会被挤下线（正常，协议是模拟客户端）

### 账号状态字段
- **在线**：已建立连接，可发消息/调接口
- **离线/缓存登录**：重启后自动用缓存恢复（免重新登录）
- **协议**：Phone 9.2.70 / Pad 9.2.70 / Linux 3.2.32（宠物仅 Android Phone/Pad 可用）

### 多账号与双会话
- 同一框架可挂多个 QQ
- 同一 QQ 可同时存在 `android` + `linux` 两个会话（平台自动控制会用到，勿手删 linux 会话）

### 删除/退出
- 账号管理 → 删除（会清空该号登录态；缓存登录数据在 `C:\mengka-nt\data\`）

---

## 3. 设备指纹（风控关键）

- 每个账号必须绑定一个设备指纹（模拟手机品牌/型号/系统）
- 「设备指纹」页可新建/编辑：品牌（如 vivo/Xiaomi/OPPO）、型号、Android 版本、OAID、指纹串
- 平台默认用 `Ann14`（vivo V2283A / Android 14）
- **更换设备指纹后必须重新登录账号**
- 风控提示（需验证/扫码）时：换设备指纹 + 重新登录基本可解

---

## 4. 插件服务（平台接入的关键）

1. 「插件服务」→「添加服务」：
   - 名称：任意（当前为「测试」）
   - 模式：`正向 WS`
   - 监听地址：`127.0.0.1:7879`
   - 保存后生成**服务令牌**
2. 服务令牌 = 平台连接萌卡的凭证（当前令牌见《敏感信息清单》）
3. 平台管理端 → 萌卡节点配置填：主机 `127.0.0.1` + 端口 `7879` + 令牌
4. 状态显示「已连接」即接入成功

> ⚠️ 令牌泄露 = 别人可控制萌卡。换令牌后需同步更新平台节点配置。

---

## 5. 协议说明

| 协议 | 用途 | 宠物支持 |
|---|---|---|
| Phone 9.2.70 | Android 手机会话 | ✅ 完整 |
| Pad 9.2.70 | Android 平板会话 | ✅ 完整 |
| Linux 3.2.32 | Linux QQ 会话 | ❌ 不支持宠物 |

- 协议文件：`C:\mengka-nt\data\protocol.json`（**勿手动改版本**，萌卡有内置白名单校验）
- 腾讯会更新客户端版本；萌卡升级说明见 v2.7.x（9.1.70 已下线，9.2.70 为当前）
- **升级萌卡**：备份 data → 替换 exe/public/docs → 启动（账号免重登）

---

## 6. QQ 宠物 API（平台调用，30 个动作）

见《运维手册》第 9 节与萌卡调试控制台（WebUI → 调试 → QQ宠物分组）。

**状态说明（2026-10-17 实测）**：
- ✅ 可用：资料/数值/属性/勋章/食物/洗护目录、活动概览/选项/状态/疲劳、PK 列表/数值、互动消息、**鼓励（encourage）**、**访问好友宠物（visit_friend_pet）**、戳一戳
- ❌ 被腾讯拦截（135064 版本过低）：**开始活动 start_pet_activity**、PK 发起/结算、活动结算——等萌卡发布 9.3 协议适配
- 规避方案：目前「开始活动」用**手机真 QQ 手动**，平台自动鼓励进行中的活动

---

## 7. 等级任务（QQ 加速）

- 「等级任务」页：按账号查看 QQ 等级加速进度、选择任务、设置自动执行计划
- 框架级功能，不受网页登录开关影响
- 与宠物无关（别指望它解决宠物活动问题）

---

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| 管理台打不开 | 进程在吗？:7878 监听？内网 127.0.0.1:7878 直测 |
| 账号离线 | 账号管理 → 重新登录（缓存登录优先） |
| 登录要滑块/验证码 | 萌卡 WebUI 会有验证提示，按提示处理；或换设备指纹重登 |
| 插件连不上平台 | 检查 :7879 监听、令牌一致、平台节点配置 |
| 自动更新 | 已开启（autoUpdate=true），有新版本自动升级重启，无需干预 |
| 升级后宠物还是 135064 | 等萌卡 9.3 协议（盯梢任务会自动升级+通知） |

---

## 9. 数据与备份

- 全部配置/登录态在 `C:\mengka-nt\data\`（config.db、protocol.json、云签名模块）
- 每日自动备份到 `C:\backup\mengka-YYYYMMDD.db`（见运维手册）
- 迁移机器：整个 `C:\mengka-nt` 拷走即可（含登录态）
