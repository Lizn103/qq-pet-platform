# 萌卡NT 使用手册

萌卡NT（MengkaNT）是提供 QQ 协议能力的框架，QQ宠物平台依赖它连接 QQ 账号。

## 登录管理台

管理台地址由部署方提供（如 `http://127.0.0.1:7878` 或公网隧道地址）。

- 首次使用需完成初始化：阅读协议 → 设置管理员账号密码
- 之后用管理员账号登录

## 账号管理

### 添加 QQ 账号
1. 左侧「账号管理」→「添加账号」
2. 选择登录方式：
   - **扫码**：生成二维码，手机 QQ 扫码确认
   - **账号+密码**：输入 QQ 号与密码，可能需要滑块验证
3. 选择协议（手机 9.2.70 / 平板 9.2.70 / Linux 3.2.32）
4. 选择设备指纹（建议选择与常用设备一致的型号，降低风控）
5. 登录成功后账号进入在线状态

### 账号状态
- 在线：心跳正常（每 6 分钟）
- 离线：点击重新登录
- 双账号：同 QQ 可同时保持 android+linux 两套会话

## 设备指纹

- 每个账号需关联一个设备指纹（品牌/型号/系统）
- 可在「设备指纹」中新建（自定义品牌型号）
- 更换设备指纹后需重新登录

## 插件服务（重要）

平台通过"正向 WebSocket 插件"接入萌卡：

1. 「插件服务」→「添加服务」
2. 模式选择 `正向 WS`
3. 端口填写（如 7879）
4. 创建后生成**服务令牌**——这是平台连接萌卡的凭证
5. 将令牌填入 QQ宠物平台的管理端节点配置

> 令牌泄露等于开放萌卡控制权，请妥善保管。

## 节点与协议

- 节点：萌卡支持单机多账号，节点是其登录位置标识
- 协议文件位于 data/protocol.json（Phone/Pad/Linux）
- 升级萌卡（如 2.6.9→2.7.1）时：替换 exe/public，保留 data 目录，账号无需重新登录

## 等级任务

- 框架内置"等级任务"（level-task）调度，与平台自动托管互补
- 可在管理台查看任务执行状态
