# 快速上手（QQ宠物平台）

本文介绍从零开始在 QQ宠物平台上注册、绑定 QQ、开始养宠的完整流程。

## 第 1 步：打开平台并注册

浏览器访问平台地址（管理员会提供公网链接，如 `https://xxx.trycloudflare.com`）。

1. 点击右上角「注册」
2. 填写用户名（3-64字符）和密码（8-64字符），确认密码
3. 注册成功后自动登录

> 如果页面提示「服务器暂时不可用」，说明平台与萌卡通道断开，联系管理员在「管理端 → 萌卡节点」重新连接即可。

## 第 2 步：添加你的 QQ 账号

登录后进入「我的 → QQ 账号」页面，点击「添加账号」，填写：

| 字段 | 说明 |
|------|------|
| QQ 号 | 你的 QQ 号码 |
| 密码 | QQ 登录密码（不会明文存储） |
| 登录节点 | 选择「本机」（萌卡NT默认节点） |
| 协议 | 选择 `Pad`（9.2.70）或 `Phone` |
| 设备指纹 | 选择一个萌卡中的设备（如 Ann01，影响风控） |
| 服务时长 | 按套餐选择月数 |

提交后可能弹出安全验证（滑块/短信/扫码），按提示完成即可。

> 说明：如果该 QQ 已在萌卡管理台扫码登录过，平台会提示「账号已存在」。此时请在萌卡管理台将该账号删除，再回到平台用密码添加。

## 第 3 步：查看你的宠物

点击左侧「宠物」→ 选择你的 QQ 账号 → 即可看到宠物卡片：
- 名字、种类、等级、经验条
- 三项属性（力量 / 智力 / 魅力）
- 心情（饱食度/清洁度/活力）

## 第 4 步：开始互动

在宠物页面可以：
- 「互动」：查看最近的互动记录
- 「活动」：学习（上课）/ 打工 / 冒险，选择具体课程开始
- 「喂养」「洗澡」：恢复宠物状态（需要先在商店购买食物/用品）

> 若「开始活动」提示"当前版本过低"，属于腾讯宠物服务端升级导致的全平台暂限，请等待平台更新。

## 第 5 步：确认账号保持在线

- 在「QQ 账号」页面看到 `状态=在线` 即正常
- 若离线，点击该账号「登录」（会通过缓存票据重新登录）

## 常见问题

- **金币怎么获得？** 宠物打工/冒险产出金币；也可用卡密兑换（管理端购买卡密发放）。
- **服务到期？** 在管理端续期或重新购买套餐。
